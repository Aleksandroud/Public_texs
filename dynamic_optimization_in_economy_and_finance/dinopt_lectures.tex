Общая задача: $f(x) \to \max,\ x\in X \subseteq \mb{R}^n$.

Решение: $x^*\in X^*$

Тогда $x^*\ -$ точка максимума, а $f(x^*)\ -$ максимум функции $f$ на множестве $X$.\\[5mm]
Случаи отсутствия максимума:
\begin{enumerate}
    \item $X = \varnothing$;
    \item $X \neq \varnothing$, но $f(x)$ не ограничена сверху на $X$;
    \item $X \neq \varnothing$, $f(x)$ ограничена сверху, но точная верхняя грань не достигается.
\end{enumerate}
\addcontentsline{toc}{section}{Оптимизация в дискретном времени}
Если $g\ -$ монотонно возрастающая, то $g(f(x)) \to \max$ даёт то же $X^*$.

Любая точка экстремума является:
\begin{enumerate}
    \item максимумом/минимумом;
    \item глобальной/локальной;
    \item строгой/нестрогой;
    \item внутренней/граничной;
    \item условной/безусловной.
\end{enumerate}
Если $\exists \varepsilon \ \forall y\in \varepsilon(x)\ (y\neq x)$ и $f(y) > f(x)$, то $x\ -$ точка локального (строгого) максимума.

\subsubsect{Безусловный экстремум}
\[f(x) \to \max \quad f\ - \text{дважды дифференцируемая}\]
Необходимое условие: $\nabla f(x_0) = 0$, где $\nabla f\ -$ градиент функции $f$.

Достаточное условие: если $H \prec 0$, где
\[H = \begin{pmatrix}
\dfrac{\partial^2 f}{\partial x_1^2} & \cdots & \dfrac{\partial^2 f}{\partial x_1 \partial x_n} \\[0.5cm]
\vdots & \ddots & \vdots \\[0.3cm]
\dfrac{\partial^2 f}{\partial x_n \partial x_1} & \cdots & \dfrac{\partial^2 f}{\partial x_n^2}
\end{pmatrix} \text{ (то есть матрица Гессе отрицательно определена),}\] 
то мы нашли точку максимума.



Критерий Сильвестра:

Пусть $\Delta_i\ -$ угловой минор порядка $i$ матрицы Гессе $H$. Тогда:
\begin{enumerate}
    \item $\Delta_1 > 0,\dots,  \Delta_n > 0 \implies \min$;
    \item $\Delta_1 < 0, \Delta_2 > 0, \Delta_3 < 0,\ldots \implies \max$;
    \item $\exists$ отрицательный чётный минор $\implies$ не экстремум;
    \item Где-то стоят нули $\implies$ требуется дополнительное исследование.
\end{enumerate}

\subsubsect{Условный экстремум с ограничениями типа равенства}
\[\begin{cases}
    f(x) \to \max & x\in\mb{R}^n\\
    g(x) = b & b\in\mb{R}^m
\end{cases}\]
где $f,\ g$ дважды дифференцируемы, $m < n$, а $X = \{x\mid g(x) = b\}$

Условие Якоби выполнено, если $\operatorname{rk}\, J_g(x) = m$, где $J_g(x)\ -$ матрица Якоби функции $g$.

В точках, где это условие не выполнено, лагранжиан не работает.\\[5mm]

Для $\lambda \in\mb{R}^m$ введём функцию $\mc{L}(x,\lambda) = f(x) + \lambda^T(g(x) - b)$

Необходимое условие:
\[\begin{cases}
    \dfrac{\partial \mc{L}}{\partial x_1} = \cdots = \dfrac{\partial\mc{L}}{\partial x_n} = 0;\\[3mm]
    \dfrac{\partial \mc{L}}{\partial \lambda_1} = \cdots = \dfrac{\partial\mc{L}}{\partial \lambda_m} = 0.
\end{cases}\]

Составим $\widehat{H} = \begin{pmatrix}
    0 & J_g(x)\\
    J_g(x)^T & H
\end{pmatrix}\ -$ матрицу Гессе лагранжиана $\mc{L}$ (окаймлённый гессиан функции $f$).

Смотрим на угловые миноры порядка от $2m+1$ до $n + m$.

Варианты:
\begin{enumerate}
    \item все миноры имеют знак $(-1)^m$ $\implies$ локальный минимум;
    \item знаки миноров чередуются, начиная с $(-1)^{m+1}$ $\implies$ локальный максимум;
    \item миноры ненулевые, но ни одно из правил выше не выполняется $\implies$ не экстремум;
    \item где-то стоят нули $\implies$ требуется дополнительное исследование.
\end{enumerate}
\subsubsect{Условный экстремум с ограничениями типа неравенства}
\[\begin{cases}
    f(x) \to \max & x\in\mb{R}^n\\
    g(x) \leq b & b\in\mb{R}^m
\end{cases}\]
где $f,\ g$ дважды дифференцируемы, $m$ может быть больше $n$ (но не обязан), а $X = \{x\mid g(x) \leq b\}$

\textit{(здесь меньше или равно значит, что вектор $g(x)$ покоординатно не превосходит вектор $b$).}\\[5mm]

Для $\lambda \in\mb{R}^m$ введём функцию $\mc{L}(x,\lambda) = f(x) + \lambda^T(b - g(x))$.

Для неё должны выполняться условия Каруша-Куна-Таккера (они же ККТ, они же дополяющей жёсткости):
\[\begin{cases}
    \forall j = 1,\dots, m\ \lambda_j \geq 0,\\
    b_j - g_j(x) \geq 0,\\
    \lambda_j(b_j - g_j(x)) = 0,
\end{cases}\]
то есть либо $\lambda_j = 0$ (нас не интересует $j$-е граничное условие), либо $b_j - g_j(x) = 0$ (мы движемся по $j$-й границе области). В худшем случае надо проверить $2^m$ вариантов активации ограничений \textit{(боже упаси)}.

В остальном алгоритм поиска экстремума аналогичен случаю с ограничениями типа равенства.

\subsubsect{Модель 1: потребление запаса.}
$x_t\ -$ запас продукта на начало периода

$c_t\ -$ потребление продукта за период $t$

$x_0\ -$ заданное значение запасов
\[0 \leq c_t \leq x_t\]
\[x_{t+1} = \alpha(x_t - c_t)\]
где $\alpha = 1\ -$ чистое распределение, $\alpha < 1\ -$ амортизация ("порча") продукта,

$\alpha > 1\ -$ производительность

Рассмотрим функцию
\[U = \sum_{t=0}^{\infty}u(c_t)\delta^t\]
Интерпретация $\delta$:
\begin{itemize}
    \item прожил период с вероятностью $\delta$
    \item закончил решать задачу с вероятностью $1 - \delta$
\end{itemize}
Тогда получается, что мы максимизируем $\mb{E}\left(\displaystyle\sum_{t=0}^{\infty}u(c_t)\right)$

Рассмотрим функцию CRRA:
\[u(c) = \frac{c^{1-\beta}-1}{1 - \beta}\]

Введём лагранжиан:
\[\mc{L} = \sum_{t=1}^{\infty}\left(u(c_t)\delta^t + \lambda_t(\alpha(x_t - c_t) - x_{t+1}) + \mu_t(x_t - c_t)\right)\]
(ограничение $c_t = 0$ никогда не реализуется в силу свойств функции полезности)
\[\begin{cases}
    \dfrac{\partial\mc{L}}{\partial c_t} = c_t^{-\beta}\delta^t - \lambda\alpha - \mu_t = 0\\[3mm]
    \dfrac{\partial\mc{L}}{\partial x_t} = -\lambda_{t-1} + \lambda_t\alpha + \mu_t = 0\\[3mm]
    \mu_t(x_t - c_t) = 0\\
    \mu_t \geq 0\\
    x_t - c_t \geq 0
\end{cases}\]
1. Может ли тогда быть $x_t = c_t$? Нет, так как в таком случае $c_{t+1} = 0$. Значит, $\mu_t = 0$.

2. Из второго уравнения:
\[\dfrac{\lambda_t}{\lambda_{t-1}} = \dfrac{1}{\alpha}\]
\[\lambda_t = \lambda_{t-1}\alpha\]
\[\lambda_t = \lambda_{t-2}\alpha^2\]
\[\vdots\]
\[\lambda_t = \lambda_{0}\alpha^{-t}\]
3. из первого уравнения:
\[c_t^{-\beta}\delta^{-t} = \lambda_t\alpha\]
\[c_t = \left(\lambda_0\delta^{-t}\alpha^{-t}\alpha\right)^{-\frac{1}{\beta}} = (\lambda_0\alpha)^{-\frac{1}{\beta}}(\delta\alpha)^{-\frac{t}{\beta}}\]
Заметим, что:
\[c_0 = (\lambda_0\alpha)^{-\frac{1}{\beta}}\]
Тогда:
\[c_t = c_0(\delta\alpha)^{-\frac{t}{\beta}} \tag{*}\]

Условие трансверсальности:
\[\lim_{t\to\infty}\alpha^{-t}x_t = 0.\]
Инструкция к поиску $c_0$:
\begin{enumerate}
    \item Выражаем $x_t$ через $x_0$ и $c_0, c_1, \ldots, c_t$;
    \item Подставляем $c_1, c_2, \ldots, c_t$, выраженные в (*);
    \item Из условия трансверсальности находим $c_0$.
\end{enumerate}
Получаем:
\[c_0 = x_0\left(1 - \dfrac{(\delta\alpha)^\frac{1}{\beta}}{\alpha}\right)\]

\subsubsect{Модель 2: потребитель, деньги, сбережения.}
\[\sum_{t=0}^{T-1}\delta^tu(c_t) \to \max\]
Финансовый баланс $(\lambda_t)$:
\[\underbrace{M_{t+1} - M_t}_{\text{наличные}} = \underbrace{w_t}_{\text{з/п}} - \underbrace{p_tc_t}_{\substack{\text{цена}\\{\text{потребления}}}} - \underbrace{(B_{t+1} - B_t)}_{\substack{\text{сбережения}\\\text{(облигации)}}} + \underbrace{r_tB_t}_{\text{доходность}}\]
Ограничения:
\begin{itemize}
    \item $M_0, B_0$ заданы;
    \item $M_t \geq 0\ -$ граничное условие $(\mu_t)$.
\end{itemize}
Решение: $\mu_tM_t = 0,\ \mu_t \geq 0,\ M_t \geq 0$ (из условия первого порядка)
\[\dfrac{\partial\mc{L}}{\partial B_t} = 0 \implies \lambda_{t-1} = \lambda_t(1 + r_t)\]
\[\dfrac{\partial\mc{L}}{\partial M_t} = 0 \implies \lambda_{t-1} = \lambda_t + \mu_t\]
Значит:
\[\frac{\lambda_t}{\lambda_{t-1}} = \frac{1}{1 + r_t}\ - \text{двойственная переменная к фин балансу мегаважна}\]

\subsect{Метод Беллмана в дискретном времени}
Здесь и далее $x_t\ -$ состояние, а $u_t\ -$ управление (как координата и импульс в физике)

Что мы будем считать решениями оптимизационной задачи:
\begin{itemize}
    \item программа: $u_0^*,\ u_1^*,\dots,u_T^*,\ldots$ при заданном $x_0$ (всё уже решено, но при поправках в начальных условиях надо всё решать заново);
    \item правило (policy): функция $u_t = \widetilde{u}_t(x_t)$ (надо решать всегда, но немного).
\end{itemize}
Принцип оптимальности:

Каждый отрезок оптимальной траектории, продолжающийся до её конца, есть снова оптимальная траектория задачи, начинающейся из достигнутого состояния

\subsubsect{Каноническая задача и функция Беллмана}
\[J = \sum_{t=0}^{T-1}F_t(x_t, u_t) + G(x_T) \to \max\]
Ограничения:

$x_{t+1} = f(x_t, u_t)\ -$ динамическое отношение между текущим состоянием и состоянием и управлением в предыдущий период

\[u_t \in U_t(x_t),\qquad t = 0,\dots,T-1\]
Будем считать, что $x_0$ задано, $x_t \in \mb{R}^n$ и $u_t \in \mb{R}^m$

Принципиальная особенность задачи:
\begin{itemize}
    \item Аддитивность: критерий $-$ сумма по периоду выигрышей, каждый из которых зависит от $x_t,\ u_t$
    \item Марковость: $x_{t+1}$ и $U_t$ зависят только от $x_t,\ u_t,\ t$ (у системы нет памяти)
\end{itemize}
Пример:

$x_{t+1} = f(x_t, x_{t-1}, u_t)$

Сделаем замену $y_t = x_{t-1}$ и $z_t = \begin{pmatrix}
    x_t\\
    y_t
\end{pmatrix}$

Тогда получаем систему
\[\begin{cases}
    y_{t+1} = x_t\\
    x_{t+1} = f(x_t, y_t, u_t)
\end{cases}\]
Функция Беллмана
\[B_{\tau}(x) = \max_{u_\tau,\dots,u_{T-1}}\left\{\sum_{t=\tau}^{T-1}F_t(x_t,u_t) + G(x_t)\right\},\qquad \text{где } x_{\tau} = x\]
(в англоязычных источниках вместо $B$ пишут $V$ (потому что value))

Ограничения:
\[x_{t+1} = f_t(x_t,u_t)\]
\[u_t \in U_t(x_t)\]
\[B_T(x) = G(x)\]
\[B_0(x) = J\]

\subsubsect{Уравнение Беллмана}
\[B_\tau(x) = \max_{x_\tau,\dots,x_{T-1}}\left[F_\tau(x_\tau,u_\tau) + \left\{\sum_{t=\tau+1}^{T-1}F_t(x_t,u_t) + G(x_T)\right\}\right] = \max_{u_\tau}\left[F_\tau(x_\tau,u_\tau) + \underbrace{\max_{x_{\tau+1},\dots,x_{T-1}}\left\{\sum_{t=\tau+1}^{T-1}F_t(x_t,u_t) + G(x_T)\right\}}_{B_{\tau+1}(x_{\tau+1})}\right]\]
при условии, что $x_{\tau+1} = f(x_{\tau},u_{\tau})$.

Итого:
\[\begin{cases}
    \displaystyle B_\tau(x) = \max_{u\in U_t(x_t)}\bigg\{F_\tau(x) + B_{\tau+1}\big(f_\tau(x,u)\big)\bigg\}\\
    B_T(x) = G(x)
\end{cases}\]

\subsubsect{Пример 1: Инвестиции в двухсекторной экономике}
$x_t\ -$ мощность отрасли производства средств производства,

$y_t\ -$ мощность отрасли производства потребительских товаров.

\[\begin{cases}
    y_T \to \max\\,
    x_{t+1} = x_t + (1 - u_t)x_ta,\\
    y_{t+1} = y_t + u_tx_ta,\\
    0 \leq u_t \leq 1,
\end{cases}\]
где $u_t\ -$ доля средств производства, использованных для расширения производства товаров потребления, а $a\ -$ коэффициент производственной функции.

Идём с конца
\[B_T = y_T\]
\[B_{T-1} = \max_{0\leq u_{T-1}\leq 1}\{0 + \underbrace{y_T}_{B_T}\} = \max_{0\leq u_{T-1}\leq 1}\left\{y_{T-1} + u_{T-1}x_{T-1}a\right\}\]
\[\boxed{u_{T-1}^* = 1}\]
\[B_{T-2}\ = \max_{0\leq u_{T-2}\leq 1}\big\{0 + \underbrace{y_{T-1} + x_{T-1}a}_{B_{T-2}}\big\} = \max_{0\leq u_{T-2}\leq 1}\big\{y_{T-2} + u_{T-2}x_{T-2}a + a(x_{T-2} + (1 - u_{T-2}x_{T-2}a))\big\}\]
\[u_{T-2}\left(ax_{T-2} - a^2x_{T-2}\right) + \cdots\]
\[\left(a - a^2\right)u_{T-2} \to \max\]
$\implies$ найдём $u_{T-2}^*$ от $a$.\\[1cm]
Результатом обратного прохода является набор $u_0^*, u_1^*, u_2^*,\dots,u_{T-1}^*$

При прямом обходе из уравнения на $x_{t+1}$ и $y_{t+1}$ найдём $x^*, y^*$

\subsubsect{Задачи с ограничением на состояния}
При наличии ограничений на состояние $x_t$ на обратном проходе вместе с $B_t$ строится два множества:
\begin{enumerate}
    \item $\underline{U}_t(x) = \left\{u\in U_t(x): f_t(x,u) \in \underline{X}_{t+1}\right\}$;
    \item $\underline{X}_{t} = \left\{x: \underline{U}_t(x) \neq 0\right\} \cap \left\{\text{ограничения в момент } t\right\}$.
\end{enumerate}
